# BUTTON COLLAGE · 纽扣拼贴设计器

一个**单文件**的网页版纽扣拼贴设计器。

打开是一段开场动画：上百颗纽扣从画面四周浮现，聚成一条手绘的散落线；**点一下任意处**进入编辑器，
把纽扣、图片、文字摆在同一个图层堆里，拖动、缩放、改颜色材质、撤销，最后导出成图片。

- **整个东西就是一个 `index.html`** —— 没有构建步骤、没有依赖、不发任何网络请求（字体也内嵌在文件里，断网可用）。
- **桌面和手机是同一个文件**，各自走各自的排版：桌面 125 颗纽扣，手机 56 颗、散得更开，并且会自动避开中间那行字。

## 本地打开

双击 `index.html`。不需要装任何东西。

## 部署到 GitHub Pages

仓库本身就是「`index.html` 在根目录」的结构，所以只要：

1. **Settings → Pages**
2. **Source** 选 `Deploy from a branch`
3. 分支选 `main`、目录选 `/ (root)`，**Save**

等一两分钟，就能在 `https://<用户名>.github.io/button-collage/` 打开。

## 说明

**体积**：`index.html` 约 21.6MB，其中约 22MB 是七款字体的 base64 字形数据。
好处是零依赖、断网也能跑；代价是**首次打开要下 16MB 左右**，网慢会等一会儿。
想瘦身就得把字体改成外链（或者删掉用不上的几款）。

**字体**：仓库只是把页面用到的字形数据一并带上，**不代表对这几款字体再授权** ——
它们各自的授权请以原发布方为准。

**开场动画**：纽扣数量、大小、散开程度等参数集中在 `index.html` 里的 `LINE` 和 `TUNE` 两个常量里，
改完刷新即可，不需要重新构建。

## 目录

```
index.html       整个应用（开场动画 + 编辑器），单文件
.nojekyll        让 GitHub Pages 跳过 Jekyll 处理
.gitattributes   让 index.html 按字节原样保存，不做换行转换
```
